🪟 Win32 Desktop Power-User Keyboard Shortcuts

Key / Shortcut Action Behavior
F4 or Alt + ↓ Toggle Dropdown Opens or closes the dropdown grid table instantly.
Alt + ↑ Close Dropdown Closes the dropdown and commits the active selection.
↓ / ↑ Row Navigation Moves active selection up or down by 1 row, scrolling the viewport smoothly.
PageDown / PageUp Page Jump Jumps selection down or up by the visible page size (10–12 rows).
Home / End Extremes Jumps directly to the very first or very last record in the dataset.
Enter Commit Selects the active row and closes the dropdown.
Esc Revert / Cancel Cancels active editing, restores previous committed value, and closes popup.
Tab Commit & Advance Commits active row and naturally moves focus to the next form control.
Space Toggle Checkbox In multi-select mode, toggles the checkbox on the currently highlighted row.

🚀 Multi-Framework Integration Guide

1. Vanilla JS / ASP.NET Web Forms (ASPX)

<script src="dist/omnicombo.standalone.js"></script> <div id="myCombo"></div> <script> const combo = omniCombo('#myCombo', { columns: [ { field: 'code', title: 'Code', width: 80 }, { field: 'name', title: 'Name', width: 200 } ], dataSource: myDataArray, displayMember: 'name', valueMember: 'code', autocomplete: true }); combo.addEventListener('change', (e) => { console.log('Selected value:', e.detail.value); }); </script>
